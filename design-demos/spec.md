## 产品
一款安卓手机「环境噪声分贝检测仪」App。打开即实时检测当前环境声压级（分贝 dB），查看统计值与历史记录。

- 中文名：咕嗄声音检测
- 英文名：GugaNoiseDetector
- 包名：com.cloudea.noise.detector（已存在 Jetpack Compose 空壳项目）
- 吉祥物：**原创扁平化小企鹅「咕嗄 / Guga」**——圆润黑白企鹅 + 豆豆眼 + 小耳机（呼应「声音检测」）。
  ⚠️ 只做原创企鹅，**不复制「咕咕嘎嘎」迷因角色的面具造型**（该 IP 版权有争议）。

## 目标用户与场景
普通用户日常环境噪音检测：家里 / 办公室 / 马路旁 / 施工现场 / 睡眠环境。App 要让人愿意随时打开——友好、可信、不专业冰冷。

## 情感基调
可爱、温暖、扁平、可信、平静。是「可爱的工具」不是「冰冷的仪器」。

## 扁平化设计约束
纯色块、圆角、无渐变或极少渐变、无投影或极轻投影。**不要**玻璃拟态、不要立体拟物。

## 核心内容板块（4 个界面 + 底部导航）

底部导航 3 个 tab：**检测 / 历史 / 关于**。

### 1. 检测主页（检测 tab，核心屏）
- 顶部：App 名 + 当前定位（城市 / 坐标，如「北京市朝阳区 · 39.9°N 116.4°E」）
- 中央：**实时分贝圆形仪表**（表盘刻度 + 指针 + 当前值大数字「42.3 dB」+ 等级标签：安静 / 正常 / 嘈杂 / 震耳）
- 统计行：**最小值 / 平均值 / 中位数 / 最大值**（4 个数据块）
- **波形图**：分贝随时间变化的折线或面积图（x = 时间，y = dB，实时滚动感）
- 一个「开始检测 / 暂停」主按钮

### 2. 历史列表（历史 tab）
- 标题「检测历史」+ 条数
- 列表卡片：每次会话 —— 时间、地点、平均 dB、最大 dB、时长、一条**迷你波形缩略图**
- 可点进详情

### 3. 历史详情（点列表项进入）
- 会话完整信息：时间范围、地点、时长
- 完整波形图 + 四统计值（min / avg / median / max）
- 可返回列表

### 4. 关于页（关于 tab）
- App logo（企鹅）+ 名称 + 版本号 `v1.0.0`
- 开发者信息、GitHub 地址（**占位**：`github.com/cloudea/GugaNoiseDetector`，需用户替换真实值）
- 一段简介文字

## 演示数据（真实感样例，非编造真实测量）
- 当前 dB：`42.3`（安静）
- 统计：最小 `31.2` / 平均 `46.8` / 中位 `44.5` / 最大 `78.9`

## 输出格式（三个 subagent 统一，否则无法横向对比）
- **单文件 HTML**，纯 HTML / CSS / 原生 JS（**不用 React / Babel**——保证 file:// 双击即开、离线可用）
- 平铺 **4–6 台安卓手机**横向并排（`flex-wrap` 自动换行），**每台上方一行斜体小字**标注这是哪个界面
- 每台 = 一个安卓设备框（规格见下），内部是 App 界面
- **每台可交互**：底部 tab 可切（检测 / 历史 / 关于）、列表项可点开详情、按钮可点 —— 用原生 JS 迷你状态机，不是静态摆拍
- 单台屏幕内容区 412×892
